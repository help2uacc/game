# Changelog

## M0 — Project setup
- Godot 4.7.2 project (Compatibility renderer, 1920×1080 canvas_items/expand, landscape, 60 FPS, 60 Hz physics).
- Android export preset (`com.blockbrawl.game`, arm64-v8a + armeabi-v7a, permissions, immersive, icons; no secrets).
- Global palette, flat unlit block shader (+ alpha variant, sky gradient, blob shadow).
- Autoload skeletons, pure rule classes (damage, kill credit, winners, colours, map rotation, discovery protocol, map data).
- Headless test runner (`tests/run_tests.gd`) with unit tests; `tools/check.sh`; `tools/validate_maps.py`.
- Branding generator (`tools/gen_branding.py`), GitHub Actions APK workflow.

## M1 — Assets
- Box-built scenes generated by `tools/build_assets.gd`: stickman (procedural animations: idle, run, jump, double-jump flip, fall, land squash, punch, shoot recoil, hold weapon, throw, hit flash, death topple/fade/pop), 6 weapons + rocket/grenade projectiles, pickups (weapon, health pack, armor), hazards (lava, spikes, crate, jump pad, moving platform).
- Shared materials, `WeaponData`/`ItemData`/`MapTheme` resources (12 themes), GridMap `MeshLibrary`, UI `Theme`.
- `tools/gen_icons.py` (27 SVG icons), `tools/gen_sfx.py` (40 SFX, 44.1 kHz), `tools/gen_music.py` (menu, 3 battle loops, results jingle, 22.05 kHz), `tools/gen_branding.py`; `tools/build_all.sh` regenerates everything.
- AudioManager (Master→Music/SFX buses, 2D/3D pools, 4-voice limit, music crossfade).

## M2 — Local sandbox
- `GameMap`: map JSON → themed GridMap (MeshLibrary blocks, octant batching), background decoration layer (Z −3…−8), far parallax layer (High), lava strips, crates, jump pads, moving platforms, spawn lists, cell queries.
- `Player` (CharacterBody3D, Z locked): run/accel, gravity, jump, double jump (one per airtime), coyote time + jump buffer, custom one-way platforms with drop-through (down + jump), knockback with 30 % control, kill line.
- `CameraRig`: FOV 40°, Z +30, −6° tilt, lerp 8/s, look-ahead 2 m, 1 m vertical dead-zone, map clamp with 2 m margin, shake, sky gradient quad.
- `TouchControls`: floating joystick, Attack/Jump/Pick Up/Throw buttons, multi-touch, latched presses, debug keyboard (A/D/S/Space/J/K/L).
- `scenes/main/sandbox.tscn` single-player sandbox; first map `candy_plains`; `tools/author_maps.py`.
- Tests: physics integration tests (floor, jump/double jump heights, one-way + drop-through, knockback, kill line); GDScript warnings-as-errors lint in `tools/check.sh`.

## M3 — Combat
- `World` authority simulation: hitscan weapons (pistol, SMG, shotgun pellets with single knockback, sniper), rockets (direct 60, splash falloff, self-damage 50 %), grenades (ballistic arc to target, bounces, 2 s fuse), punch, auto-aim (§7.2: nearest enemy in range with line of sight, facing tie-break), damage armor→HP, knockback, kill credit (§4.3).
- Pick Up (drop-on-swap with ammo), Throw (15 dmg, knockback 6, lands as pickup with ammo), ammo removal, 30 s ground despawn with 3 s blink, health/armor items (auto pickup, caps).
- Hazards: lava (instant death), spikes (34 dmg, bounce, 0.5 s invulnerability), crates (30 HP), jump pads (20 m/s), moving platforms; environmental kill credit.
- Spawning rules (§7.5): 3 weapons at fight start, +1 every 8 s up to 6, items at 30 s then every 20 s up to 2, free-point rule, spawn weights.
- Event system (`GameEvents`) driving VFX/SFX: pooled cube bursts, tracers, muzzle flash, explosions + shockwave ring, damage numbers, crate break, landing dust, jump-pad puff, screen shake.
- Tests: 19 combat integration tests.

## M4 — Networking
- `NetManager`: ENet host/join (port 47820), handshake with protocol version check ("Version mismatch — update the app"), "Game is full", in-match joins refused except reconnecting tokens, 5 s connect timeout ("Could not connect"), host leave/close → "Host left the game", ping every 1 s, fast ENet timeouts.
- Reconnect (§5.5): UUID v4 session token, `user://session.cfg`, 60 s slot window on the server, automatic retries every 2 s with "Reconnecting… (Xs)" overlay, REJOIN button, disconnect while alive = death with 5 s credit rule, rejoiners spectate until the next round, released slots keep greyed kills.
- `LanDiscovery`: broadcast probe + /24 unicast sweep every 2 s, unicast replies, 6 s host expiry (JSON packets per §5.2).
- `GameState` replicated roster: unique colours, names, ready, rounds 4–99, START conditions; lobby RPCs.
- `MatchManager` RPC hub: 60 Hz unreliable_ordered inputs with latched presses + ack, 30 Hz packed snapshots (~0.6 KB for 8 players), batched reliable events, map load sync (`load_map` → `map_ready`, 10 s timeout), 100 ms interpolation buffer on clients.
- Screens: main menu (animated background, name prompt, REJOIN), join (host list + manual IP), lobby (slots, colour picker, name, ready, rounds stepper with long-press, START, leave confirm), game screen (HUD, controls, menu/reconnect overlays), settings, match results.
- `tools/net_smoke_test.sh`: automated localhost match with 1 host + N bot clients (debug-only args), including a simulated connection loss.
